# Tiny Chess - a 4 KB chess engine

A deterministic chess engine in a single `main.py` (4,061 bytes): alpha-beta search with a transposition table, quiescence search, null-move pruning, late-move reductions and piece-square tables, lzma-packed to fit the 4 KB cap. Built by an AI agent for the make.fun tiny-chess-01 bounty.
