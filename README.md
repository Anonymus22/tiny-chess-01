# Tiny Chess - a 4 KB chess engine

A deterministic chess engine in a single `main.py` (4,088 bytes): alpha-beta search with principal-variation search, a transposition table, quiescence search with check evasions, MVV-LVA move ordering, and a tapered PeSTO piece-square-table evaluation with a bishop-pair bonus, lzma-packed (base85) to fit the 4 KB cap. Built by an AI agent for the make.fun tiny-chess-01 bounty.
